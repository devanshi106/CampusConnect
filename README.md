# CampusConnect

CampusConnect is a campus event and student networking platform.

## Purpose

CampusConnect provides a centralized platform where students can:

- Discover college events
- Register for events
- Create student profiles
- Find teammates based on skills and interests

Clubs and student councils can:

- Create events
- Manage participants
- Communicate event information

College administrators can:

- Review campus activities
- Manage events
- Oversee student organizations

## Tech Stack

### Frontend

### Backend
- Java
- Spring Boot

### Database
- PostgreSQL
